# Screenshots

Name files `YYYY-MM-DD-<slug>.png`, matching the log entry.

Before committing a screenshot, check it does **not** show:
- raw GRID data: event JSON, `.jsonl` lines, tables of per-round rows, series IDs from the data;
- file explorers or terminals listing the data folder contents;
- tokens, API keys, emails.

Junie/Air chat panels, diffs, test output, charts of aggregates and the app UI are fine.
Crop to the part that tells the story. Keep each file under ~500 KB.
